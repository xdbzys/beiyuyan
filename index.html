02 / 背词逻辑

看原句 → 判义项 → 说现代义，答案唯一绑定这一句。

最小练习单位是「例句 + 义项」，而不是「一个字」。同一字在不同句子里意思不同，必须回到语境里判断。

1

看原句

先给教材或真题原文与出处，不给任何提示义项；语境、作者、朝代一并呈现。

2

判义项

四选一选出该字在此句中的义项，干扰项两两去重；简单 / 困难两档可切换。

3

说现代义

再说出现代意思（4 选 1 或填空），等价判定按确定性规则，不做模糊匹配。

判定后立刻展开解析区：高考考点精讲（句法成分 · 词性 · 为何这样译）、同义项全部例句、运用场景与关联特殊句式；确有词类活用 / 古今异义才显示对应段落，没有就不占空间。也可以在「更多设置」里打开「答后展开词条全文」，一次看全这个词在词库里的全部意思、例句与关联词。常用开关做成两列彩色磁贴排在背诵页上，带图标和当前状态、点一下就切换，开与关用颜色区分，题目和选项打开就能看到；还可以用音量键翻到下一题。温习会把最近做过的题按原句原义再考一遍；词库新增与实词库、虚词库并列的「错词库」，错题按词归拢随时可复习。进度、错词本与设置自动双份保存并生成快照，升级或清理存储后打开会自动恢复；网页版和软件版打开都是最新版本。

03 / 例句与出处

每条例句都能追到篇目、作者与朝代，一个字都不编。

同一个「之」字，在下面两句里的意思完全不同，只有回到原句才判得准。

《烛之武退秦师》 · 左丘明 · 先秦

是寡人之过也。

语境：郑文公向烛之武认错。
该字在此句中：的，连接领属定语「寡人」与中心语「过」。
全句翻译：这是我的过错。
《烛之武退秦师》 · 左丘明 · 先秦

公从之。

语境：佚之狐建议派烛之武出使，郑文公采纳。
该字在此句中：他 / 这件事，代佚之狐的建议。
全句翻译：郑文公听从了他（佚之狐的建议）。

07 / 常见问题

为什么更新了页面还要装新包？为什么断网也能背？

网页更新和 APK 更新有什么区别？

点「立即更新」后，网页版会直接换成新页面，进度和错词本都保留；安卓版则打开官网下载页，由系统安装新包。 包名、权限、图标这类原生能力只能随 APK 升级，网页更新不会补上。

换包名了，旧版背词进度怎么办？

本版包名为 com.beiyuyan.wenyan，与旧包不同，无法覆盖安装，进度也不自动继承。 从旧版升级：先在旧版「我的」导出备份，安装本包后在同一页导入恢复。可卸载旧版，也可两包并存。

安装时提示「未知来源 / 安装未知应用」？

APK 为自签名包，未走应用商店。请在系统「设置 → 安装未知应用」里允许用于安装的文件管理器或浏览器，然后重新点击安装包。应用内不做静默安装，也不申请安装权限。

断网还能背吗？检查更新会耗流量或上传数据吗？

能。核心功能完全离线，进度只存本机。本版只新增一条 INTERNET 权限，用途仅限读取本站版本清单与用户主动前往下载； 无账号、无埋点、无统计、无上传接口、不访问第三方域名。断网、清单不可达或校验失败一律静默跳过，不重试、不弹阻塞。

深浅色怎么切换？会记住吗？

官网右上角、App 顶栏与「我的 → 设置」都可切换。首次跟随系统偏好，之后记忆在本机，不上传。
